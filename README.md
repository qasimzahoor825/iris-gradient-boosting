# 🌸 Iris Flower Classification using Gradient Boosting

This project demonstrates **Gradient Boosting Classifier** on the classic Iris dataset.  
The model is trained to classify iris flowers into three species based on sepal and petal dimensions.

## 🚀 Features
- Uses scikit-learn's Iris dataset
- Implements Gradient Boosting (Ensemble Learning)
- Evaluates performance using confusion matrix, classification report, and accuracy
- Visualizes feature importance with a bar plot
- Supports XGBoost for comparison

## 📊 Output
- Accuracy score on test set
- Confusion matrix
- Classification report
- Feature importance plot

## 🛠️ Tech Stack
- Python
- scikit-learn
- Matplotlib
- NumPy
- XGBoost

## 📌 Example Use Cases
- Learning ensemble models
- Understanding feature importance
- Introductory ML classification project
